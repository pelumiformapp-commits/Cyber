CYBERLAB

Simulated attacks. Runs locally. Nothing real is attacked or collected.

🎣 Phishing Lab

🛡️ Fix: read the real domain (the part right before the first /), distrust urgency, type the portal address yourself, enable MFA.

🔐 Password Lab

Use sample passwords only, never your real one. 





🛡️ Fix: long passphrases, a unique password per site, a password manager, MFA. Reuse is dangerous because one leak opens every account.



💉 SQL Injection Lab

Valid login: student / pass123. Try: admin'-- or password ' OR '1'='1








🛡️ Fix: never build SQL by joining strings. Use db.query("... WHERE user = ? AND pass = ?", [u, p]), hash passwords, give the DB account least privilege.



🧪 XSS Lab

Try a comment like: <img src=x onerror=alert(1)>







🛡️ Fix: vulnerable code does el.innerHTML = comment. Safe code does el.textContent = comment. Also add a Content-Security-Policy and validate input.



📶 Network Lab

You are the attacker on the same Wi-Fi as the victim. This is a simulated capture, like Wireshark. Use sample credentials only.










🛡️ Fix: only log in over HTTPS (padlock), avoid open Wi-Fi or use a VPN, use WPA3 with client isolation, enable HSTS on the server.



💻 Ransomware Lab

Disposable fake files only. Try infecting with and without a backup.








🛡️ Fix: offline backups made BEFORE the attack, patching, email filtering, endpoint protection, least privilege. Paying never guarantees recovery.



🚨 DoS Lab

Local simulation. Server capacity is 60 req/s, legit users send 10 req/s.

Attacker rate: 0 req/s





🛡️ Fix: rate limiting, traffic monitoring and alerts, CDN or DDoS protection, caching, autoscaling.
